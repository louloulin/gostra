# Graph RAG（知识图谱增强检索生成）示例

这个示例展示了如何使用Gostra框架实现一个完整的Graph RAG（知识图谱增强检索生成）系统，该系统将传统的向量检索与知识图谱技术相结合，提供更加上下文感知的答案。

## 功能特点

- 文档处理和分块
- 使用OpenAI嵌入API生成文本嵌入
- 基于向量相似度构建知识图谱
- 使用PageRank等图算法增强检索结果
- 利用Actor架构实现异步消息处理
- 通过知识图谱发现文档片段之间的隐含关系

## 技术原理

Graph RAG扩展了传统的RAG系统，主要创新点在于：

1. **知识图谱构建**：系统不仅检索相关文档片段，还分析它们之间的关系，构建一个基于相似度的知识图谱。
2. **图遍历算法**：使用PageRank等算法在图上进行遍历，找出不仅直接相关，而且在上下文中重要的节点。
3. **关系发现**：通过分析图结构，可以发现文档中原本不明显的关联信息。

## 前置要求

1. 安装PostgreSQL（版本14+）并启用pgvector扩展
2. 设置必要的环境变量
3. 安装Gostra依赖项

## 项目结构

- `main.go`：主程序文件，包含Graph RAG示例的完整实现
- `graph_types.go`：知识图谱相关数据结构定义
- `graph_rag_tool.go`：Graph RAG工具的实现
- `graph_util.go`：知识图谱构建和遍历的辅助函数

## 运行示例

1. 设置必要的环境变量
   ```
   export OPENAI_API_KEY="your-openai-api-key"
   export POSTGRES_CONNECTION_STRING="postgresql://username:password@localhost:5432/ragdb"
   ```

2. 从Gostra根目录运行示例
   ```
   cd gostra
   go run examples/graph_rag/main.go
   ```

```

回答:

   - 1870年铁路连接到河谷镇，极大促进了当地经济发展

   - 铁路建设(1870年)与煤矿开始运营(1885年)、人口突破2,500人(1891年)之间存在时序关联，表明铁路带动了资源开发和人口增长
   - 铁路改善了交通连接，促进了工业化进程，间接促成了后续工业繁荣期(1900-1950)的到来，包括钢铁厂、纺织厂和机械制造厂的建立
   - 铁路作为交通连接形式，与河谷镇从农业到工业再到服务业和知识经济的经济基础变化相互影响，形成城市发展的长期轨迹

3. 结论:
   铁路不仅直接促进了河谷镇19世纪末的经济和人口增长，还作为关键基础设施间接塑造了整个城市的发展路径，从初期工业化到现代多元经济，体现了交通基础设施对城市长期发展的深远影响。
```

## 应用场景

Graph RAG技术特别适合以下场景：

1. **复杂文档分析**：理解大型文档中的关系和模式，如学术文献、技术文档等
2. **历史和事件分析**：理解历史事件之间的因果关系和影响
3. **多维度数据理解**：处理具有多个相互关联维度的信息，如案例研究
4. **决策支持系统**：通过揭示信息之间的隐含关系辅助决策

## 扩展可能性

2. 集成预训练的知识图谱以增强背景知识
3. 实现更复杂的图算法，如社区检测
4. 添加知识图谱可视化界面
